# Phishing URL Detection System

## Overview
A beginner-friendly cybersecurity project that analyzes URL
patterns using Python and Machine Learning to flag potentially
suspicious links.

## Technologies
- Python
- Streamlit
- Pandas
- Scikit-learn
- Random Forest Classifier

## Features
- URL input and basic validation
- URL feature extraction
- Machine Learning classification
- Suspicion score and feature display
- Interactive Streamlit dashboard

## Important Limitation
This version uses a small synthetic demonstration dataset.
It is not suitable for real-world security decisions.
The model's score is not a verified probability of phishing.

## Run Locally
1. Install the dependencies:
   pip install -r requirements.txt

2. Run the application:
   streamlit run app.py
